StatsCo AI

ask Colombia's official statistics in plain language
Live

A bilingual chat app: ask “What was the unemployment rate in Antioquia in 2023?” and it answers with the number and its sources. An LLM gate filters the question, sentence embeddings pick the right tables, then the model writes SQL that runs read-only against a 1.8 GB SQLite database — retrying on failure — and replies in text, or as a Plotly chart / department map on request.
